# 关卡难度平衡 V2

## 目标

- 保留旧版 50 关作为 `legacy` 对照组，新增默认 `balanced-v2`。
- 难度不再由“针数 + 速度 + 障碍数”的线性和决定，而是使用阈值曲线与交互项。
- 相邻关只引入一个主要变化；预测难度单关增幅不超过约 4 分。
- 第 10 关不再同时叠加四障碍、四短相位、正反转和击中后翻转。

## 难度模型

1. **空间密度**：使用 `待插针数 / 当前障碍布局的舒适容量`，在低占用区影响很小，接近舒适容量后按幂函数快速上升。障碍数量不单独粗暴相减，而是按每个障碍分割出的扇区逐区计算容量。
2. **转速压力**：平均速度和峰值速度分别经过带阈值的凸曲线；低速差异几乎不计，高速区每次提速都会明显增加压力。
3. **节奏压力**：由相位数、最短相位、方向变化、速度反差、边界突变、相位时长不规则共同决定。
4. **击中后状态变化**：逐针加速、按针数翻转、按针数移相分别计入，多个状态修改会叠加。
5. **操作提前量**：针飞行与插入锁定期间转盘继续旋转，高速下需要更大的预判。
6. **交互增益**：密度×速度、密度×分区、速度×节奏、密度×击中后变化会额外加分，避免低估多机制同时出现的关卡。
7. **机会摩擦**：完整圆周最坏等待时间单独记录，用于识别“不是难，而是等得烦”的节奏；不把它大量混入操作难度分。

## 章节结构

- 1–10：校准与留白。先分别教密度、单障碍、双障碍、呼吸、双拍、逐针加速、回摆。
- 11–20：分区判断。增加 3–5 个分区，但仍控制相位数和速度上限。
- 21–30：节奏控制。引入高速、三相、移相和四相，但空间压力不一次跳满。
- 31–40：复合压力。进入 8 区与窄区，交替训练速度、回摆和相位读取。
- 41–50：专家终曲。高密度、四相、五相、移相和翻转逐步组合，最后才完整叠加。

## 测试方式

- 主菜单进入“选关测试 · A/B 对照”。
- 可在 `平滑曲线 V2` 和 `旧版 50 关` 之间切换。
- 每章显示 10 关，卡片展示模型难度分；悬停显示主要压力、针数、障碍数和相位数。
- 测试模式可直达全部关卡，通关不会修改正常解锁进度。
